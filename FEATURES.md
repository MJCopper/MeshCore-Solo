# Zen features

Zen v2.27 is based on MeshCore v1.17.1 for the Wio Tracker L1.

| Area | Behaviour |
| ---- | --------- |
| Messaging | Direct, channel and room transcripts, replies, quick messages, unread tracking and manual resend |
| Delivery | Fixed direct-path/flood retry policy, live route state and channel echo counts |
| Text entry | EN-US ABC and predictive T9 with a 4,000-word Australianised dictionary |
| Emoji | Monochrome common emoji, diamond fallback and four insertable chat emoji |
| CardKB | Boot detection, direct input, compact editor and screen-aware polling |
| Clock | Permanent first page, unread count, latest-conversation shortcut and GPS time sync |
| GPS | Off, Continuous and timed 2 min–6 h modes |
| Sensors | Saved sensor nodes, on-demand telemetry, descending channels and line scrolling |
| Favourites | Four editable contact shortcuts with unread badges |
| Child Mode | Parent PIN, favourite-only messaging and disabled companion access while locked |
| Quiet Time | Daily local-time sound suppression while visual alerts and unread state continue |
| Advert | Off/1 h/3 h/6 h interval and shared GPS privacy control |
| Repeater | Current radio settings, fixed backend timing, Yield x2 and duplicate suppression |
| Tools | Discover Repeaters, Node List, Repeater Mode, Ringtone Editor and Diagnostics |
| Node Admin | ACL/password login, remote settings, radio, console and confirmed actions |
| Persistence | Settings save on exit only when changed; Zen preferences use a versioned sidecar |

Detailed guides are linked from [README.md](./README.md).
